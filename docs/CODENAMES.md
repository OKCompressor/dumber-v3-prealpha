# DUMBer development codenames

DUMBer development releases may carry moon codenames in addition to their
technical version numbers.

| codename | development lane |
|---|---|
| Europa | bounded streaming input |
| Ganymede | large global identity space / u32 |
| Io | hot-path and memory optimization |
| Enceladus | streaming model epochs |
| Titan | giant-corpus / full-Wikipedia profile |
| Triton | reverse mapping and token-space transduction |
| Callisto | compatibility / interchange |
| Rhea | reducer-tree experiments |
| Dione | graph / metadata integration |
| Mimas | minimal core profile |

Codenames are aliases only. Reproducibility material continues to use explicit
technical version numbers and Git hashes.
